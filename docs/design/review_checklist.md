# 禾记（Heji Notes） 设计评审清单

## 使用方式

用于需求评审、交互评审、代码评审和 Mate 真机验收。每项标记为“通过”“不适用”或“例外”；例外须记录原因、受影响平台、用户影响、临时处理和补齐计划。涉及正文、附件或保存语义的改动，同时核对相应功能规格与共享 Vault 契约。

## 1. 范围与一致性

- [ ] 变更已关联功能规格，并更新了受影响的设计文档。
- [ ] Android APK 与 HAP 对同一操作给出相同结果、保存时机和错误恢复语义。
- [ ] 平台差异只影响控件表达，不改变 Markdown、相对路径或 Vault 结果。
- [ ] 未把正文、附件或凭据引入不透明的私有存储或日志。
- [ ] 导航层级、返回目标和顶级区域的边界符合 [组件规范](components.md)，且不会重置用户上下文。

## 2. 内容与保存

- [ ] 用户始终知道正在编辑哪个 Vault 和笔记。
- [ ] 编辑后的“未保存、正在保存、已保存、保存失败”状态可见且含义准确。
- [ ] 保存成功仅在正文及相关附件都可恢复写入后显示。
- [ ] 保存失败、权限失效和空间不足时，用户输入保留，且有明确的下一步。
- [ ] 未静默重命名、移动、覆盖或复制用户文件；冲突保留两个版本并可发现。
- [ ] 字符、列表、链接、标签和双向链接不会因显示或自动格式化而丢失。

## 3. 页面与组件

- [ ] 页面只有一个清晰主操作；重要图标按钮有文字或辅助技术标签。
- [ ] 文件库分组容器、分隔线和首尾圆角在空、单行和多行状态下清晰；图标使用统一平台语义，装饰图标不会形成独立辅助技术焦点。
- [ ] 搜索能区分空、进行、无结果、部分读取失败和 Vault 无法读取；结果排序、每日状态、相对时间、返回上下文和只读边界符合组件规范。
- [ ] 日间/夜间的主色、系统主题、编辑器与对话框一致；主按钮、文字、分隔线、链接和焦点/按压状态均有足够对比度，夜间浅色主按钮使用可读文字色。
- [ ] 加载、空、错误、无权限和完成状态均已设计，非仅成功路径。
- [ ] 破坏性操作说明影响，并优先提供撤销、回收站或确认。
- [ ] 用户取消系统相机或文件选择器时，回到原上下文且不显示错误。
- [ ] 瞬时提示未被用作唯一的保存、失败或恢复信息来源。
- [ ] 远端同步在页面之外运行；离开设置、旋转或编辑本地笔记不会取消任务或阻止输入、保存。
- [ ] 同步详情持续显示当前或最后一次的目标、进度、结果、冲突和错误；完成/失败通知不暴露路径、账号、URI 或正文，通知关闭时设置入口仍可发现状态。
- [ ] 同步扫描后出现同路径本地内容时，本地内容和远端冲突副本均保留，不会静默覆盖。
- [ ] 动效只说明方向、直接操作或状态变化；可中断、不阻塞操作，并在减少动态效果时有非动态反馈。
- [ ] 显示模式有明确已选状态并在重启后保持；切换不影响正文或附件。
- [ ] 语言设置可明确选择中文或 English（Android 另有跟随系统）；切换立即生效且重启后保持，
  默认/回退符合组件规范。所有库、设置、编辑、相机、搜索、回收站、同步、通知和辅助技术文案
  均随当前语言呈现。
- [ ] Vault 文件名、`Daily Notes`、`.trash`、`assets`、`.markbook`、Provider 名称和持久
  Markdown（含视频标记、冲突后缀）未被翻译或改写；持久同步状态不含已渲染的本地化消息或错误。
- [ ] 今日笔记目录选择仅在用户明确确认后生效，且不会移动既有 Vault 内容。
- [ ] 清空回收站明确显示项目数、不可撤销后果和附件保留规则；取消无副作用，部分失败
  保留未删除项目并提供重试。
- [ ] 回收站页面只列根 `.trash/` 直接项目；读取 Markdown 使用独立只读查看器。单项和清空永久删除均按已确认快照执行，文件夹不递归删除，新增项目不被旧确认误删。
- [ ] 文件库的新建、重命名和移到回收站均有加载、冲突、非法名称、取消和 Provider 失败路径；操作期间不会重复提交或覆盖已有条目。
- [ ] 回收站移动会区分队列等待、Provider 移动与列表复核；确认成功后立即从当前列表移除条目且保留滚动位置，失败则保留原条目与恢复入口。
- [ ] 主文件库普通笔记与文件夹的左滑操作只显示文字明确、不同色块且至少 44 × 44 dp 的“重命名”“删除”；删除仍须确认并移到回收站，滑动本身不会删除，展开/收起、返回、相邻或页面其他点击与长按菜单均可预测。
- [ ] 主文件库显示 `assets` / `attachments` 目录及其中图片、视频和其他附件；文件名、类型、大小与系统查看器失败反馈清晰。仅图片/视频显示至少 44dp、可访问名称明确的永久删除入口；文件夹、其他文件和 Markdown 不可删除，且均不出现新建、重命名、移动或左滑操作。
- [ ] assets 中永久删除使用独立持久事务：两次全 Vault 精确引用扫描、身份复核和严格删除结果确认；被引用、不可读、模糊、外变或同步占用时保留文件，绝不删除兄弟文件或 bundle。
- [ ] 左滑操作在 TalkBack 下保留“重命名 <名称>”“移到回收站 <名称>”自定义入口；收起时底层操作不可聚焦，展开时状态会被读出。
- [ ] 有可左滑条目时，一次性行内提示可被读出、关闭或显示后不会在重启后重复出现；清除应用数据后才会重新显示。
- [ ] 普通笔记与文件夹共享名称空间并按 NFC/不区分大小写检查冲突；已有不合规名称仍可浏览。
- [ ] 非空文件夹只整体移动到 Vault 根 `.trash/`；Provider 不支持或失败时源目录保持原样，未执行递归 copy-delete。
- [ ] 移动或重命名未改写 Markdown 链接、未自动清理附件；影响每日笔记配置时已重置到 Vault 根并持续提示。
- [ ] “移动到…”仅移动独占的笔记附件 bundle，确认页说明目标、链接重写边界和入站链接不更新；共享引用、不可读 Markdown、目标冲突或未完成事务均保守失败。同步空闲时不依赖网络即可移动；同 Vault 同步运行时在写 marker 前拒绝。

## 4. Markdown 编辑器

- [ ] 打开、编辑、自动保存、手动保存、后台、返回与恢复行为符合 [编辑器规范](note_editor.md)。
- [ ] 输入法组合文本、光标、选区和滚动位置不会被自动保存或格式化打断。
- [ ] 编辑器紧凑元数据仍完整暴露当前 Vault/目录/文件与持续保存状态；失败状态包含不被截断的恢复动作。
- [ ] Markdown 的标题、段落、列表、链接、图片和原始块在深浅色下可读；视觉增强没有改变可编辑 DOM 的支持范围或 Markdown 往返结果。
- [ ] 格式工具栏的标题/加粗/斜体选中态与撤销/重做可用态不依赖颜色、不会移动光标或破坏输入法。
- [ ] 插入图片、链接或格式操作发生在用户的光标或选区处。
- [ ] 长按正文图片或视频可选择“仅从正文删除（保留附件）”或“删除正文引用并永久删除附件”；前者不创建标记且不改附件，后者继续使用安全事务。取消不修改正文或附件。正文以媒体结尾时存在可触达的后续输入行，轻点媒体可将光标移到其后。
- [ ] 离开有未保存内容的页面前，用户可继续编辑、重试保存或明确放弃本次改动。
- [ ] 深度为 0、1 和 3 的普通笔记插图时，生成链接均从该笔记真实父目录指向 Vault `assets/`，且拍照上下文未误用每日目录。
- [ ] “拍摄”明确区分拍照与录视频；视频确认页显示大小、时长、取消、重新录制与插入，且系统相机取消不显示错误。

## 5. 拍照与附件

- [ ] 相机从系统入口启动，拍摄、处理、写入和插入顺序符合 [拍照流程](capture_flow.md)。
- [ ] 取消、相机失败、权限拒绝和空间不足不会修改原正文或留下死链接。
- [ ] 原图与校正图均保存到当前 Vault；Markdown 只使用 Vault 内相对路径。
- [ ] 原图、校正图、正文三者的事务失败可恢复或安全清理，异常结束不破坏已完成内容。
- [ ] 连续拍摄的插入顺序、暂存状态和重复操作限制均明确。
- [ ] 视频使用系统相机原样写入 `-v.mp4` 或 `-v.3gp`，正文为含尖括号相对路径的普通链接；编辑器将本地视频呈现为带可访问播放按钮的 16:9 卡片并可直接播放，序列化不改写标签或路径；无录音、媒体读取、转码或剪辑权限/能力。
- [ ] 待处理视频会话只保存定位与校验信息；外部正文变更或任意 Markdown 不可读时，正文和附件均采取保守保留策略。
- [ ] final rename 返回空或异常时仍保留 marker；已保存的视频链接恢复时只清理 marker、缓存和 pending 会话，且链接序列化在空格或括号路径上保持 `(<...>)` 格式。

## 6. 可访问性与设备适配

- [ ] 支持系统字体放大、深浅色外观、竖横屏、安全区域和不同屏幕密度。
- [ ] 触控目标至少 44 × 44 dp，文本与图标的对比和状态不只依赖颜色。
- [ ] 关键状态、图片、图标操作和错误能被辅助技术理解。
- [ ] 键盘打开时，当前输入行和主要编辑动作仍可见或可到达。

## 7. 验证与交付

- [ ] 已对正常、空、加载、错误、取消、恢复和重复操作逐一验证。
- [ ] 已用共享 Vault 样例或真实 Vault 确认电脑 Obsidian 可读取输出。
- [ ] 涉及相机的改动已在 Mate 真机验证拍摄、重启和相对链接有效性。
- [ ] 已记录平台限制、已接受例外与后续补齐任务。
