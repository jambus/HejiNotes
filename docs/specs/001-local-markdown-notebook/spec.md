# Feature Specification: Obsidian Vault 本地笔记

**Status**: In Progress  
**Priority**: P1  
**Depends on**: None

## Platform Scope

本规格同时适用于 HarmonyOS 4 Android APK 与 HarmonyOS 5/6 原生 HAP。
两端可以采用不同编辑器和文件 API，但必须产生相同的 Vault 文件结果。

## User Stories

### US1 选择 Vault 并快速记录（P1）

用户可以选择已有 Obsidian Vault，在指定的每日笔记目录中打开或创建当天笔记，
使用所见即所得编辑器记录内容，并在离开编辑器或应用退出前可靠保存。

**Acceptance**: 两端分别新建含中文、列表和链接的笔记，重启应用后内容逐字一致。

### US2 浏览与查找（P1）

用户可以按文件夹和最近修改顺序浏览笔记，并通过标题、正文、标签和双向链接
找到目标笔记。

**Acceptance**: 在 1,000 篇笔记的测试库中输入关键字，可得到正确结果且输入
过程无明显卡顿。

### US3 文件可迁移（P1）

用户可以将完整笔记本作为普通目录备份和恢复，不依赖 禾记（Heji Notes） 专有数据库。

**Acceptance**: 将目录复制到新安装环境后，笔记与附件引用仍可打开。

## Functional Requirements

- **FR-001** 系统必须将每篇笔记保存为 UTF-8 `.md` 文件。
- **FR-002** 系统必须保留用户 Vault 中的文件名、目录结构和相对链接；标题变化
  不得自动移动或重命名文件。
- **FR-003** 系统必须提供自动保存并防止异常退出丢失已输入内容。
- **FR-004** 系统必须提供删除与可恢复的回收站流程。
- **FR-005** 系统必须支持标题和正文搜索。
- **FR-006** 索引损坏或丢失时必须能从文件重建。
- **FR-007** 系统必须正确处理空标题、重名标题和非法文件名字符。
- **FR-008** 用户必须可以配置每日笔记目录；默认快速记录进入当天的每日笔记。
- **FR-009** 编辑器必须支持常用 Markdown、`[[双向链接]]` 和 `#标签`，并以
  所见即所得方式呈现。
- **FR-010** 每次编辑必须持续自动保存，并提供手动保存入口。
- **FR-011** 删除的笔记必须先移入 Vault 根目录 `.trash/`，不上传、下载或作为远端删除依据；恢复与永久删除必须是后续明确操作。
- **FR-012** 编辑器必须提供撤销、重做、加粗、斜体、H1 至 H5/正文、标签、链接和表格的
  常用 Markdown 操作；结果必须是 Obsidian 可读取的标准 Markdown，取消参数输入不得修改正文。
- **FR-013** 系统必须提供明确的“清空回收站”操作：执行前显示 `.trash/` 项目数并二次
  确认，确认后仅永久删除 Vault 根目录 `.trash/` 的直接内容，不删除附件；部分失败必须
  保留未删除项目并允许重试。
- **FR-014** 系统必须支持在当前普通目录新建 Markdown 笔记和文件夹、重命名普通笔记或
  文件夹，并将它们整体移至 Vault 根 `.trash/`。名称须按共享 Vault 契约校验且不覆盖；
  内部目录和 Vault 根不可管理。深层笔记的附件链接必须从真实父目录计算；每日目录在被
  移除或成为无效路径时重置为 Vault 根并告知用户。
- **FR-015** 系统必须提供仅显示 Vault 根 `.trash/` 直接项目的回收站浏览；Markdown 只读查看不改写字节。单项或清空永久删除必须确认不可撤销、附件保留和文件夹后果，并仅对确认快照执行；不提供递归删除或应用内恢复。
- **FR-016** 系统必须提供显式“移动笔记及附件”操作：将笔记和其独占 `assets/<stem>/` bundle 移至同一 Vault 目标目录，并仅重写该笔记的本地相对附件链接。所有 Markdown 必须可读且不得有其他笔记引用该 bundle；冲突、共享、未完成事务、外部变化或不确定 Provider 结果均保留源内容并可恢复。
- **FR-017** 每日笔记目录和目录失效持续提示必须按稳定 Vault 身份独立保存在设备本地；新 Vault 默认 `Daily Notes`。重命名、移除、重新选择或清除提示只影响当前 Vault。旧版全局目录只可幂等迁移到迁移时已保存的 Vault。

## Out of Scope

拍照处理、同步协议、反向链接视图、关系图谱和插件生态不属于首版范围。
