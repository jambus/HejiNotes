## 前置条件

- Mate 60 使用 HarmonyOS 4，开启开发者模式和 USB 调试。
- 连接后保持手机解锁，并在手机上确认本电脑的 USB 调试/调试密钥授权提示。
- 准备一个已有 Obsidian Vault，并确认电脑端 Obsidian 可以打开它。
- 使用 Java 11+ 从 `android/` 执行 `./gradlew :app:testDebugUnitTest :app:assembleDebug`。
- 待安装 APK 为 `android/app/build/outputs/apk/debug/app-debug.apk`。

本机命令行打包必须显式使用 DevEco JBR 与 Android SDK，避免 `ANDROID_HOME` 未设置：

```bash
cd android
JAVA_HOME=/Applications/DevEco-Studio.app/Contents/jbr/Contents/Home \
ANDROID_HOME="$HOME/Library/Android/sdk" \
./gradlew :app:clean :app:assembleDebug
```

连接设备后可运行 `./scripts/install-apk.sh` 自动选择 `adb` 或 `hdc` 安装 APK。
若脚本提示 `connect-key`，先在手机确认调试密钥，再重新执行，不要跳过授权继续验收。

## 验收步骤

1. 安装 APK，记录设备型号、HarmonyOS 版本、Android 兼容层 API、APK 版本和构建来源。
2. 首次打开应用，选择已有 Vault；确认没有生成 禾记（Heji Notes） 私有正文副本或数据库。
3. 创建或打开当天笔记，输入中文、标题、列表、标签和 `[[双向链接]]`；分别等待自动
   保存和触发手动保存。
4. 关闭并重新打开应用，确认内容仍在原 Vault 中；重启手机后再次确认目录授权有效。
5. 拍照后分别测试直接插入、矩形裁剪和四点透视校正，并连续插入至少两张照片。
6. 检查 `assets/<笔记文件名>/` 中存在同一拍摄 ID 的 `o`、`c` 文件；Markdown 使用
   Vault 内相对链接且默认指向校正图。
7. 分别在照片写入和正文保存过程中强制结束应用；重启后不得出现死链接、孤儿附件、
   静默副本或无法解释的临时事务文件。
8. 在系统设置中撤销目录权限；重新打开后应要求重新选择 Vault，重新授权后继续编辑
   原目录，不得创建替代 Vault。
9. 在最大系统字体下分别使用竖屏和横屏完成文件浏览、编辑、保存和照片处理。
10. 将至少两篇笔记移入回收站；进入“设置 → 存储”，确认显示正确项目数。第一次确认框
    选择“取消”，检查 `.trash/` 内容不变；再次进入并选择“永久删除”，确认项目数归零。
11. 检查 `assets/` 和旧 `attachments/` 中的图片仍存在；若模拟某项删除失败，未删除项目
    必须保留，设置页显示成功数、失败数并允许重试。
12. 在电脑 Obsidian 中打开同一 Vault，确认中文、Markdown 结构和校正图片无需转换即可读取。
13. 在根目录及深度 1、3 的普通目录分别新建笔记，验证中文/emoji 名称、大小写/NFC 冲突和
    非法名称提示；确认笔记被立即打开，并在每层插图后检查链接都正确指向 `assets/`。
14. 新建非空文件夹后，分别重命名、移到 `.trash/` 和取消操作；确认 Markdown 链接未被
    改写、附件未删除。若 Provider 拒绝移动，源目录及内容必须不变。
15. 把已配置的每日笔记目录或其祖先移到回收站，确认设置被重置为 Vault 根目录并持续提示；
    再次打开今日笔记必须在根目录创建或打开。
16. 点按“拍摄 → 录视频”，录制短视频后确认大小和时长；取消、重新录制与插入均回到原笔记上下文。确认 Vault 写入 `-v.mp4` 或 `-v.3gp`，正文为含尖括号的相对链接，点按后由系统播放器打开。
17. 验证 180 秒/200 MiB 限制、相机忽略输出时可读返回 URI 的处理，以及相机取消无错误；录制或复制时强制结束并重启，外部修改正文后确认不会覆盖且缓存仍可取消/重试。
18. 在正文保存成功、marker/cache 清理前强制结束并重启，确认既有视频链接不重复插入，只完成清理；模拟 Provider final rename 返回空/抛错及伪装 `.mp4` 文件，确认 marker 保留、伪容器被拒绝。
19. 同步空闲时长按普通笔记并选择“移动到…”，在根目录、深度 1 和深度 3 间移动含图片/视频的笔记；确认笔记与同级 `assets/<笔记名>/` 均移动、链接有效，移动期间关闭网络仍成功。
20. 同 Vault 同步运行时尝试移动、重命名和移到回收站；确认在创建任何 marker 前被拒绝。同步结束后可再次移动。
21. 完成初始 Drive 同步后搬运笔记并再次同步；在 Drive 与电脑 Obsidian 确认新路径完整、旧项在回收站。分别在上传目标和回收旧项后强制结束或断网，再重试并确认旧路径不复活。
22. 按 `../003-remote-sync/android-onedrive-oauth-setup.md` 配置 debug 签名对应的 Entra Android
    应用；分别以个人和组织 Microsoft 账号登录，选择/创建 OneDrive Vault，并确认取消授权不改绑定。
23. 使用 OneDrive 同步含 Markdown、小图片和大于 4 MiB 附件的 Vault；后台编辑同路径笔记、取消、
    断网、撤销授权并重试，确认冲突副本、上传会话、持续详情与成功基线符合 Google Drive 同一语义。
24. 在同一本地 Vault 分别配置 Google Drive 与 OneDrive，切换设置页和运行任务；确认两套绑定、
    root、账号、最近成功时间与基线不串用，且同一时刻只有一个 Provider 占用 Vault 同步租约。
