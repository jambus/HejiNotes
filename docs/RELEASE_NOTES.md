# 禾记（Heji Notes）Release Notes

本文档记录禾记（Heji Notes）每个可识别版本的功能范围、交付状态、兼容性说明和后续事项。
Android APK 与 HarmonyOS HAP 分别维护安装包版本；两端共享 Vault 契约，但不因功能
相近而复用版本号或隐含彼此已经完成验收。

## 版本管理规则

- 版本号采用 `MAJOR.MINOR.PATCH`。`1.0.0` 之前为开发阶段：`MINOR` 表示一组可体验的
  功能迭代，`PATCH` 表示不扩大功能范围的修复或小幅体验优化。
- Android 的 `versionName` 使用本文档中的完整版本号，`versionCode` 每次生成可分发
  安装包时单调递增，不得复用已经发布过的值。
- 每次准备新版本时，先在本文档新增版本条目，再同步平台规格、任务状态和安装包配置。
- 版本条目必须区分“开发基线”“候选版本”和“已发布”；只有完成对应真机验收并留存
  构建记录后，才能标记为“已发布”。
- 尚未完成的优化不写入“已实现功能”，统一关联到对应编号规格的未完成任务。

- 文件库管理：在当前目录新建 Markdown 笔记或文件夹、重命名、移到 Vault 根 `.trash/`，并以 NFC/大小写无关规则防止冲突。
- 文件库左滑：普通条目左滑显示“重命名”和“删除”；删除仍须确认后移到回收站，保留长按和 TalkBack 等价入口。
- 短视频：编辑器“拍摄”可选择拍照或系统相机录视频；视频原样写入当前笔记附件目录并插入相对 Markdown 链接。
- 后台同步：Google Drive 同步由独立前台后台任务执行；用户可继续浏览、打开和保存本地笔记，设置中的“同步详情”持续显示进度、结果、冲突与失败文件，并在完成或失败时发送不含路径、账号或 URI 的系统通知。
- 同步保护：任务启动时固定本地 Vault 与远端目标；同步范围仅含 Markdown 和 `assets/`。若下载期间出现同路径本地内容，保留本地文件并另存远端冲突副本，避免静默覆盖。
- 回收站移动：结构性文件操作不再排在普通读取和保存之后；回收站移动会说明等待、移动和后台列表复核阶段，确认成功后立即从当前列表移除条目并保留滚动位置。
- 文件库体验：采用连续分组、原生图标和深浅色统一反馈；笔记显示相对修改时间与精确的“今日笔记”标识，顶部提供搜索与更多操作入口。
- Vault 搜索：只读递归匹配普通 Markdown 笔记的标题、纯文本正文和标签，不创建数据库或写入 Vault；结果保留查询与返回上下文，并显示匹配来源、目录、时间和每日状态。
- 编辑体验：保存元数据不重复显示文件名；格式栏呈现标题/加粗/斜体选中态及撤销/重做可用态。图片或视频成功插入后定位到实际位置并给予一次可减少动态效果的反馈。
- 回收站：设置中的“回收站”可浏览 Vault 根 `.trash/` 直接项目；Markdown 以只读模式查看。单项删除与清空均需确认，并只删除确认快照中的项目；文件夹由 Provider 整体删除，附件保留。列表右侧使用垃圾桶图标作为永久删除入口，保留可访问名称与二次确认。

### 视频边界

- 视频限制为 180 秒/200 MiB，接受具备有效 MP4/3GP 容器和 video 轨的文件。
- 使用不复制正文的 pending 会话、附件/提交阶段、可取消流式复制、hash 外变保护和 marker 恢复确保异常不会覆盖、重复插入或留下死链接。

## 0.1.0 — Android APK 当前开发基线

**基线日期**：2026-08-26  
**状态**：开发基线，Mate 60 HarmonyOS 4 真机发布验收尚未完成  
**安装包版本**：`versionName = 0.1.0`，`versionCode = 1`

### 已实现功能

#### Vault 与文件库

- 使用系统目录选择器选择 Obsidian Vault，并持久保留目录访问授权。
- 以 Vault 文件库作为启动页，显示当前 Vault、目录路径、文件夹和 Markdown 笔记。
- 笔记列表显示首段摘要，支持逐层进入目录并在返回时保留浏览上下文和滚动位置。
- 提供固定的“打开今日笔记”入口；每日笔记按 `yyyy-MM-dd.md` 创建或打开。
- 支持将笔记确认后移入 Vault 根目录 `.trash/`；附件不会被连带永久删除。
- 区分空目录和 Vault 无法读取状态，并提供重新选择 Vault 的恢复入口。

#### Markdown 编辑

- 提供基于 WebView 的所见即所得编辑器，以及手动保存和约 600 ms 防抖自动保存。
- 持续显示“未保存”“正在保存”“已保存”和“保存失败”等状态。
- 提供撤销、重做、H1–H5、加粗、斜体、标签、链接和表格工具。
- 对围栏代码块、表格、有序列表、引用、任务列表和 YAML front matter 等结构采用
  原文保留策略，避免打开或保存时静默破坏未编辑内容。
- 保留 Markdown 相对链接语义，并阻止富文本粘贴直接引入任意 HTML。

#### 拍照与附件

- 从编辑器调用系统相机，并在取消时返回原笔记上下文。
- 提供矩形裁剪和四点透视校正，进入处理页即显示可拖动的默认选区。
- 同时保存原图和校正图到 Vault，并在原光标位置插入 Vault 内相对 Markdown 图片链接。
- 附件与正文按事务顺序写入；失败时回滚不完整结果并保留重试路径。
- 插入成功后恢复原阅读位置，支持继续输入和连续拍摄。

#### 设置与同步

- 支持日间/夜间显示模式，并持久保存选择。
- 支持选择 Vault 内的今日笔记目录；设置变化不移动既有笔记或附件。
- 设置页提供完整中文和 English，语言选择即时应用并在重启后保持；Android 默认跟随系统
  （非中文回退 English），HAP 默认中文。该偏好与 Vault 内容、路径和同步目标隔离。
- 已实现 Google Drive 账号连接、远端文件夹选择/创建、同步范围确认、双向比较、
  进度与取消、冲突副本和结果摘要的初始流程。
